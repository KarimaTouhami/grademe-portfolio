# mini_scanf

Implement a compact scanf-like reader for strings, integers, and characters

```c
int mini_scanf(const char *format, ...)
```

**Difficulty:** 5/5
**Allowed functions:** fgetc, ungetc, ferror, feof, isspace, isdigit, va_start, va_arg, va_copy, va_end

Solved as level 1 of the algorithms-parsing challenge.
