# free_str_array

Release a NULL-terminated array of heap strings in the only order that works, and report how many strings it held

```c
size_t free_str_array(char **arr)
```

**Difficulty:** 3/5
**Allowed functions:** free

Solved as level 2 of the pointers-and-memory challenge.
